# Тестирование API сервиса Яндекс.Самокат

## Описание проекта

Проект содержит автоматизированные тесты для API сервиса Яндекс.Самокат. Тесты покрывают основные функции:
- Создание курьера
- Авторизацию курьера
- Создание заказа
- Получение списка заказов

## Структура проекта
Sprint_7/
├── tests/ # Директория с тестами
│ ├── test_create_courier.py # Тесты создания курьера
│ ├── test_login_courier.py # Тесты авторизации курьера
│ ├── test_create_order.py # Тесты создания заказа
│ └── test_orders_list.py # Тесты получения списка заказов
├── test_data.py # Тестовые данные
├── courier_helpers.py # Вспомогательные функции для работы с курьерами
├── conftest.py # Фикстуры pytest
├── requirements.txt # Зависимости проекта
└── README.md # Документация
